Composite Trapezoidal Rule Calculator

1. Mathematical Discussion

The Composite Trapezoidal Rule is a numerical integration method used to approximate the definite integral of a continuous function: $$\int_{a}^{b} f(x) \, dx$$ Instead of evaluating the entire interval using a single trapezoid, the interval $[a, b]$ is divided into $n$ equal subintervals, each of width $h = \frac{b - a}{n}$. The area under the curve is approximated by summing the areas of these smaller trapezoids.

General Formula: $$\int_{a}^{b} f(x) \, dx \approx \frac{h}{2} \left[ f(a) + 2 \sum_{i=1}^{n-1} f(x_i) + f(b) \right]$$ where $x_i = a + i \cdot h$ for $i = 0, 1, \dots, n$.

2. Worked Examples (Step-by-Step)

Example 1: Polynomial Integration

Approximate $\int_{0}^{2} x^2 \, dx$ using $n = 4$ subintervals.

  • Step 1: Compute step size $h$: $h = \frac{2 - 0}{4} = 0.5$
  • Step 2: Generate grid points ($x_i$): $x_0 = 0.0, \; x_1 = 0.5, \; x_2 = 1.0, \; x_3 = 1.5, \; x_4 = 2.0$
  • Step 3: Evaluate function values $f(x_i) = x_i^2$:
    $f(0.0) = 0.0, \; f(0.5) = 0.25, \; f(1.0) = 1.0, \; f(1.5) = 2.25, \; f(2.0) = 4.0$
  • Step 4: Apply Formula: $$\int_{0}^{2} x^2 \, dx \approx \frac{0.5}{2} \left[ 0.0 + 2(0.25 + 1.0 + 2.25) + 4.0 \right]$$ $$\approx 0.25 \left[ 0.0 + 2(3.5) + 4.0 \right] = 0.25 \left[ 11.0 \right] = 2.75$$

Analytical Exact Value: $2.667$ | Approximation: $2.75$

Example 2: Trigonometric Integration

Approximate $\int_{0}^{\pi} \sin(x) \, dx$ using $n = 4$ subintervals.

  • Step 1: Compute step size $h$: $h = \frac{\pi - 0}{4} = \frac{\pi}{4} \approx 0.7854$
  • Step 2: Generate grid points ($x_i$): $x_0 = 0, \; x_1 = \frac{\pi}{4}, \; x_2 = \frac{\pi}{2}, \; x_3 = \frac{3\pi}{4}, \; x_4 = \pi$
  • Step 3: Evaluate function values $f(x_i) = \sin(x_i)$:
    $f(0) = 0.0, \; f(\frac{\pi}{4}) \approx 0.7071, \; f(\frac{\pi}{2}) = 1.0, \; f(\frac{3\pi}{4}) \approx 0.7071, \; f(\pi) = 0.0$
  • Step 4: Apply Formula: $$\int_{0}^{\pi} \sin(x) \, dx \approx \frac{\pi/4}{2} \left[ 0.0 + 2(0.7071 + 1.0 + 0.7071) + 0.0 \right]$$ $$\approx 0.3927 \left[ 2(2.4142) \right] \approx 0.3927 \times 4.8284 \approx 1.8961$$

Analytical Exact Value: $2.0000$ | Approximation: $1.8961$
